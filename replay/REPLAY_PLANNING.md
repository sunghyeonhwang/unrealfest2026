# 언리얼 페스트 서울 2026 다시보기 페이지 기획서

> 문서 상태: 개발 전달용 초안 1.0  
> 작성일: 2026-09-15  
> 구현 예정 위치: `/unrealfest2026/replay/`  
> 예상 서비스 URL: `https://epiclounge.co.kr/unrealfest2026/replay/`

## 1. 프로젝트 개요

언리얼 페스트 서울 2026 종료 후 정상 등록된 오프라인 참가자에게 세션 영상과 강연 PDF를 제공하는 등록자 전용 다시보기 페이지를 구축한다.

사용자는 행사 등록 당시 입력한 이메일과 연락처로 다시보기 체크인을 진행한다. 서버에서 오프라인 등록 자격을 확인한 사용자만 강연 목록, Vimeo 영상, 강연 PDF에 접근할 수 있다.

이 문서에서 말하는 **다시보기 체크인**은 행사장의 QR 현장 체크인이 아니라, 다시보기 페이지에서 수행하는 등록 정보 기반 본인 확인 절차다. 실제 현장 방문 여부는 확인하지 않는다.

## 2. 목표

- 정상 등록된 오프라인 참가자에게만 다시보기 콘텐츠를 제공한다.
- 온라인 전용 등록자는 제외한다.
- 기존 강연 정보를 재사용해 중복 입력과 운영 오류를 줄인다.
- Vimeo 영상의 외부 사이트 임베드와 일반적인 링크 공유를 제한한다.
- 강연 PDF는 제공 예정인 Cloudflare 폴더에 운영자가 업로드하고, 사이트에서는 세션별 링크를 연결한다.
- 관리자가 영상과 PDF를 세션별로 독립적으로 공개하거나 숨길 수 있게 한다.
- 모바일과 데스크톱에서 간편하게 체크인하고 콘텐츠를 이용할 수 있게 한다.

## 3. 비목표

다음 항목은 초기 개발 범위에 포함하지 않는다.

- 실제 행사장 QR 체크인 여부 확인
- 온라인 전용 등록자 대상 다시보기 제공
- 사이트 서버에 PDF 파일 직접 업로드
- 관리자 페이지에서 Cloudflare 파일 생성·업로드·삭제
- Vimeo에 영상을 자동 업로드하는 기능
- 화면 녹화나 촬영을 기술적으로 완전히 차단하는 기능
- 다운로드된 PDF의 2차 재배포를 완전히 차단하는 기능
- 결제·등록 시스템 자체의 변경

## 4. 확정 이용 정책

### 4.1 이용 가능 대상

다음 조건을 모두 만족하는 오프라인 등록자는 다시보기를 이용할 수 있다.

- 정상 등록 완료 상태
- 임시 등록이 아님
- 등록이 취소 또는 환불되지 않음
- 온라인 전용 상품이 아님

대상에는 다음 유형을 포함한다.

- 오프라인 유료 등록자
- 오프라인 무료 쿠폰 등록자
- 오프라인 초청 등록자
- 오프라인 단체 등록 참가자
- Day 1 등록자
- Day 2 등록자
- 양일권 등록자

실제 행사장 방문이나 QR 현장 체크인 기록은 요구하지 않는다.

### 4.2 이용 불가 대상

- 온라인 전용 등록자
- 취소 또는 환불된 등록자
- 결제 대기 상태인 등록자
- 임시 등록 상태인 사용자
- 입력한 이메일과 연락처가 등록 정보와 일치하지 않는 사용자

### 4.3 콘텐츠 접근 범위

초기 정책은 자격을 통과한 모든 오프라인 등록자에게 관리자가 공개한 전체 세션을 제공하는 것으로 한다. Day 1권이나 Day 2권에 따라 콘텐츠를 나누지 않는다.

### 4.4 관리자 예외

권한이 있는 기존 사이트 관리자는 운영 점검을 위해 사용자 체크인을 우회할 수 있다. 관리자 우회 여부가 일반 사용자 세션에 영향을 주어서는 안 된다.

## 5. 현재 프로젝트와의 관계

현재 프로젝트 루트에는 기존 `replay.php`가 존재한다. 이 파일은 등록 정보 확인 후 YouTube 영상을 재생하는 구조이며, 현재 조건만으로는 온라인 등록자를 명확하게 제외하지 못할 수 있다.

신규 다시보기는 다음 방향으로 구성한다.

- 신규 구현 위치는 `/unrealfest2026/replay/`로 한다.
- 기존 등록 DB, 기존 세션 DB, 관리자 권한 체계는 재사용한다.
- 영상 플랫폼은 YouTube가 아닌 Vimeo를 사용한다.
- 온라인 전용 등록자를 명시적으로 제외한다.
- 강연 PDF와 기존 강연 상세 정보를 함께 제공한다.
- 기존 루트 `replay.php`의 처리 방법은 신규 페이지 완성 후 결정한다.
  - 신규 페이지로 이동 처리
  - 관리자 테스트용으로 유지
  - 운영에서 제거

## 6. 전체 사용자 흐름

```text
다시보기 URL 접속
→ 인증 상태 확인
→ 미인증 사용자는 체크인 화면 표시
→ 이메일 + 연락처 입력
→ 서버에서 등록 정보 및 오프라인 자격 확인
   ├─ 성공: 인증 세션 발급 후 강연 목록 이동
   └─ 실패: 통합 오류 안내
→ Day/트랙/검색을 이용해 강연 탐색
→ 강연 선택
→ 기존 강연 정보 확인
→ Vimeo 다시보기 재생 및/또는 강연 PDF 열기
→ 로그아웃 또는 인증 만료
```

등록 당시 정보를 이용해 오프라인 등록 자격을 확인한다.

#### 구성 요소

- 언리얼 페스트 서울 2026 로고
- 페이지 제목: `세션 다시보기`
- 체크인 안내
- 이메일 입력란
- 연락처 입력란
- `다시보기 입장` 버튼
- 온라인 등록자 제외 안내
- 오류 메시지 영역
- 사무국 문의처

#### 기본 안내 문구

> 언리얼 페스트 서울 2026 오프라인 등록자를 위한 다시보기 페이지입니다. 등록 시 입력한 이메일과 연락처로 체크인해 주세요.

> 다시보기 이용 대상 정보를 확인할 수 없습니다. 등록 시 입력한 이메일과 연락처를 확인해 주세요.

보조 문구:

> 온라인 전용 등록자는 다시보기를 이용할 수 없습니다.

### 7.4 영상 재생 방식

초기 버전은 세션 상세 영역에 Vimeo 플레이어를 배치한다. 목록 카드 선택 시 상세 화면 또는 동일 페이지 내 상세 영역으로 이동한다.

영상별 URL을 제공한다면 다음과 같은 구조를 사용할 수 있다.

```text
/unrealfest2026/replay/watch/?id={세션ID}
```

영상 상세 URL로 직접 접근해도 서버가 인증 상태와 이용 자격을 다시 확인해야 한다.

## 8. 기존 강연 정보 연동

### 8.1 원칙

강연 정보는 사이트에 이미 등록된 기존 세션 데이터를 재사용한다. 다시보기용으로 동일한 강연 정보를 별도 저장하거나 중복 입력하지 않는다.

### 8.2 재사용 대상

- 세션 고유 번호
- 행사 일자
- 시작 및 종료 시간
- 트랙명
- 세션 제목
- 세션 소개
- 발표자 이름
- 발표자 소속
- 발표자 직함
- 발표자 프로필 이미지
- 발표자 소개
- 온라인 중계 제외 여부
- 기존 노출 및 정렬 순서

### 8.3 연동 규칙

- 다시보기 전용 데이터는 기존 세션 고유 번호를 연결값으로 사용한다.
- 기존 강연 정보가 수정되면 다시보기에도 반영한다.
- 기존 세션이 삭제 또는 비활성화되면 다시보기에서도 기본적으로 노출하지 않는다.
- Vimeo ID, 다시보기 썸네일, PDF 링크, 공개 상태만 다시보기 전용으로 관리한다.
- 기존 세션 정보가 없는 특별 영상이 필요한 경우만 관리자 직접 입력 기능을 별도 검토한다.

### 8.4 온라인 중계 제외 세션

기존 `온라인 중계 제외` 표시는 행사 당시 실시간 중계 정책이다. 이를 다시보기 금지로 자동 해석하지 않는다.

다시보기 영상과 PDF의 공개 여부는 발표자 동의 및 운영 정책에 따라 관리자가 세션별로 결정한다.

| 공개 | 비공개 | 비공개 | 강연 정보와 준비 상태 표시 |
| 비공개 | 무관 | 무관 | 세션 전체 미노출 |

새 콘텐츠는 기본적으로 비공개 상태로 등록하고 관리자 확인 후 공개한다.

## 10. Vimeo 영상 정책

### 10.1 업로드 및 연결

- Vimeo 업로드는 운영자가 Vimeo에서 직접 수행한다.
- 사이트 관리자에는 Vimeo 영상 ID와 필요한 비공개 해시를 등록한다.
- Vimeo 업로드 자동화는 MVP에 포함하지 않는다.

### 10.2 Vimeo 권장 설정

- 영상 공개 범위: `Embed only` 권장
- 임베드 허용 위치: `Specific domains`
- 허용 도메인: 실제 운영에 사용하는 `epiclounge.co.kr` 호스트
- `www.epiclounge.co.kr`을 사용한다면 실제 운영 호스트를 확인해 추가
- 테스트용 도메인은 검수 후 허용 목록에서 제거
- 다운로드 권한 비활성화
- Vimeo 검색 및 공개 페이지 노출 최소화
- 추천 영상과 불필요한 공유 기능 최소화

Vimeo 요금제에 따라 일부 공개 및 임베드 옵션이 달라질 수 있으므로 운영 계정에서 사전 확인한다.

### 10.3 보안 범위

Vimeo 도메인 제한은 외부 사이트가 iframe을 복사해 재생하는 행위를 제한한다. 다만 화면 녹화, 촬영, 인증된 브라우저 공유, 전문적인 추출 시도까지 완전히 막을 수는 없다.

서비스의 보호 수준은 다음과 같이 정의한다.

- 일반적인 외부 사이트 임베드 제한
- Vimeo 공개 페이지를 통한 일반 접근 제한
- 기본 다운로드 기능 비활성화
- 인증 전 영상 정보 노출 방지
- 완전한 DRM 제공은 범위 밖

## 11. Cloudflare PDF 정책

### 11.1 저장 및 등록 방식

- PDF는 운영자가 제공 예정인 Cloudflare 지정 폴더에 직접 업로드한다.
- 사이트 서버에는 PDF 파일을 업로드하지 않는다.
- 관리자 페이지에서는 업로드된 PDF 링크만 세션에 연결한다.
- 세션당 PDF 1개를 기본으로 한다.
- PDF 교체 시 Cloudflare에서 파일을 교체하고 관리자에서 링크를 갱신한다.

### 11.2 운영 흐름

```text
강연 PDF 준비
→ 제공된 Cloudflare 폴더에 업로드
→ PDF 링크 확인
→ 관리자에서 기존 세션 선택
→ PDF 링크 등록
→ PDF 공개 상태 설정
→ 사용자 화면에 강연자료 버튼 노출
```

### 11.3 권장 파일 구조

실제 구조는 추후 제공되는 폴더를 기준으로 한다. 신규 구성이 필요할 경우 다음 구조를 권장한다.

```text
/unrealfest2026/replay/pdf/
├── day1/
│   ├── ufs2026-day1-001-session-title.pdf
│   └── ufs2026-day1-002-session-title.pdf
└── day2/
    ├── ufs2026-day2-101-session-title.pdf
    └── ufs2026-day2-102-session-title.pdf
```

파일명은 영문 소문자, 숫자, 하이픈을 사용하고 개인정보나 내부 경로 정보를 포함하지 않는다.

### 11.4 링크 등록 검증

- HTTPS 주소만 허용
- 운영자가 지정한 Cloudflare 도메인만 허용
- PDF 파일 또는 PDF 응답 여부 확인
- 잘못된 URL 형식 차단
- 링크가 없거나 열리지 않아도 사용자 화면 전체가 깨지지 않게 처리
- 링크 테스트 기능 제공

### 11.5 공개 고정 링크 사용 시 주의

Cloudflare 링크가 공개 고정 URL이면 체크인 후에만 버튼을 보여도 사용자가 링크를 복사해 전달할 수 있다. 이 경우 서비스가 보장할 수 있는 수준은 **인증 전 사이트 화면에서 링크를 노출하지 않는 것**까지다.

공개 고정 링크를 사용할 경우 다음을 적용한다.

- 인증 전 HTML에 PDF URL을 넣지 않는다.
- Cloudflare 폴더 목록 탐색을 허용하지 않는다.
- 검색엔진 및 사이트맵에 PDF를 포함하지 않는다.
- 추측하기 어려운 파일명을 사용한다.
- `r2.dev` 개발 주소보다 운영용 커스텀 도메인을 권장한다.

### 11.6 등록자 전용 접근을 강화할 경우

Cloudflare 저장소가 비공개 R2 버킷이고 관련 접근 정보가 제공된다면 다음 방식을 권장한다.

```text
PDF 버튼 선택
→ 서버에서 다시보기 인증 확인
→ 오프라인 등록 자격 확인
→ PDF 공개 여부 확인
→ 짧은 유효기간의 임시 다운로드 URL 생성
→ PDF 열기
```

임시 URL의 권장 유효시간은 5~15분이다. 이 방식은 Cloudflare 환경과 접근 키 제공 여부가 확정된 후 개발 범위를 결정한다.

### 12.3 직접 접근 차단

## 16. 보안 및 개인정보 보호

- 모든 페이지와 콘텐츠 요청을 HTTPS로 처리
- 이메일과 연락처를 서버 로그에 그대로 출력하지 않음
- SQL 입력값에 준비된 쿼리 또는 안전한 이스케이프 적용
- CSRF 방어 적용
- 반복 실패 요청에 속도 제한 적용
- 인증 성공 후 세션 ID 재발급
- 세션 쿠키에 `Secure`, `HttpOnly`, `SameSite` 적용
- 관리자 페이지는 기존 관리자 인증 및 권한 사용
- Vimeo ID와 PDF URL을 인증 전 HTML에 포함하지 않음
- iframe에는 필요한 권한만 허용
- 페이지에 `noindex, nofollow` 적용
- 영상과 PDF를 공개 사이트맵에 포함하지 않음
- 등록자별 개인화 페이지는 CDN 및 브라우저 공유 캐시에서 제외

권장 캐시 정책:

```text
Cache-Control: private, no-store
Pragma: no-cache
```

Cloudflare/CDN에서도 `/unrealfest2026/replay/*`의 인증 페이지 HTML은 캐시하지 않도록 한다. PDF 자체의 캐시 정책은 제공될 Cloudflare 저장 방식에 맞춰 별도로 설정한다.

## 20. 사용자 스토리 및 인수 조건

### 스토리 1: 오프라인 등록자 체크인

오프라인 등록자로서 등록 당시 이메일과 연락처로 본인 확인하고 다시보기 페이지에 들어가고 싶다.

인수 조건:

- 정상 오프라인 등록자는 체크인에 성공한다.
- 현장 방문 기록이 없어도 체크인에 성공한다.
- 온라인 전용 등록자는 실패한다.
- 취소·환불·결제 대기·임시 등록자는 실패한다.
- 잘못된 이메일 또는 연락처는 실패한다.

### 스토리 2: 강연 탐색

등록자로서 기존 행사 일정과 강연 정보를 기준으로 원하는 세션을 찾고 싶다.

인수 조건:

- Day, 시간, 트랙, 제목, 발표자 정보가 기존 데이터와 일치한다.
- 기존 세션 정보가 중복 저장되지 않는다.
- Day 및 트랙 필터가 정상 동작한다.
- 비공개 세션은 노출되지 않는다.

### 스토리 3: 영상 시청

등록자로서 선택한 강연의 Vimeo 영상을 사이트 안에서 재생하고 싶다.

인수 조건:

- 공개 영상만 재생된다.
- 인증되지 않은 사용자는 직접 URL로 접근해도 영상을 볼 수 없다.
- Vimeo 영상은 허용하지 않은 외부 도메인에서 임베드 재생되지 않는다.
- 다운로드 버튼이 노출되지 않는다.
- 모바일과 데스크톱에서 정상 재생된다.

### 스토리 4: 강연자료 이용

등록자로서 세션에 공개된 강연 PDF를 열고 싶다.

인수 조건:

- PDF가 공개된 세션에만 강연자료 버튼이 표시된다.
- 영상 없이 PDF만 공개할 수 있다.
- PDF 없이 영상만 공개할 수 있다.
- 인증 전 HTML에는 PDF 링크가 노출되지 않는다.
- 잘못된 링크가 있어도 페이지 전체가 깨지지 않는다.
- 모바일 브라우저에서 PDF가 정상적으로 열린다.

### 스토리 5: 관리자 콘텐츠 운영

관리자로서 기존 세션에 Vimeo 영상과 Cloudflare PDF 링크를 연결하고 각각 공개 상태를 관리하고 싶다.

인수 조건:

- 기존 세션을 선택할 수 있다.
- Vimeo ID와 PDF 링크를 각각 등록·수정·제거할 수 있다.
- 영상과 PDF를 독립적으로 공개하거나 숨길 수 있다.
- 관리자 미리보기 및 링크 테스트가 가능하다.
- 새 콘텐츠는 기본 비공개 상태다.

## 21. 개발 전 제공·확인 항목

### 운영자가 제공할 항목

- Vimeo 운영 계정 및 영상 ID 목록
- Vimeo에서 사용할 정확한 허용 도메인
- Cloudflare PDF 폴더 및 기본 URL
- Cloudflare 링크가 공개 고정 URL인지 비공개 R2인지에 대한 정보
- 세션별 PDF 파일과 연결 목록
- 다시보기 공개 시작일과 종료일
- 발표자별 영상 및 PDF 공개 동의 결과
- 사용자 문의처 문구

### 개발자가 확인할 항목

- 실제 등록 완료 상태값
- 온라인 전용 상품을 구분하는 정확한 상품 코드
- 무료 쿠폰·초청·단체 등록자의 상태값
- 기존 세션 DB와 발표자 데이터 구조
- 기존 관리자 권한 판정 방식
- 기존 루트 `replay.php` 처리 방식
- Cloudflare가 비공개 R2일 경우 임시 URL 생성에 필요한 접근 방식
- 운영 도메인의 `www` 사용 여부

## 22. 최종 완료 기준

- 정상 등록된 오프라인 참가자는 현장 방문 여부와 관계없이 입장할 수 있다.
- 온라인 전용 등록자와 유효하지 않은 등록자는 입장할 수 없다.
- 기존 강연 정보가 다시보기 페이지에 정확히 표시된다.
- 공개된 Vimeo 영상만 재생된다.
- Vimeo 영상이 허용 도메인 외 사이트에서 임베드 재생되지 않는다.
- 공개된 Cloudflare PDF 링크만 표시된다.
- 영상과 PDF를 독립적으로 공개할 수 있다.
- 영상만, PDF만, 둘 다 또는 세션 정보만 제공하는 상태가 모두 정상 동작한다.
- 인증 전 영상 정보와 PDF URL이 노출되지 않는다.
- 직접 URL 접근, 로그아웃, 세션 만료 시 권한 검사가 정상 동작한다.
- 모바일에서 체크인, 강연 탐색, 영상 재생, PDF 열기가 정상 동작한다.
- 관리자에게 영상과 PDF 등록·검수·공개 기능이 제공된다.
- 사용자 화면과 관리자 화면에서 오류 상태가 안전하게 처리된다.
